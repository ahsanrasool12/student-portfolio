# University Clubs Portal

A small informational website that introduces student clubs, events, and how to join them.
Built for DevOps Fundamentals (Fall 2026), Assignment 01.

## Structure

```
student-portfolio/
├── .gitignore
├── README.md
├── src/        index, clubs, events, join, highlights (.html)
└── styles/     style.css (shared by all pages)
```

## Branching Strategy

- `main`: production-ready code (3 approvals required)
- `develop`: active development (2 approvals required)
- `feature/<page-name>`: one branch per team member
- `release/v1.0`: release testing branch
